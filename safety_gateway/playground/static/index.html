這不是「AI 比較會聊天」，而是兒童資料與不安全話題進不了模型

小孩很常主動報上姓名、電話、身分證。模型一旦看到，就可能寫進日誌或後續回合講出來。

按送出之後，閘道會先做台灣個資代號化、內容安全檢查、蘇格拉底教學包裝，通過才呼叫 Gemini。出站再還原給小朋友，並寫一筆給家長看的紀錄。

  • 降低外洩面： Google 端看不到真名、真電話、真身分證。
  • 不安全話題： 色情、血腥暴力、恐怖驚嚇、自傷、毒品菸酒檳榔、仇恨言語、賭博會被攔住，不會送到 Gemini。
  • 對話生圖（測試頁）： 說「畫」或「產生圖片」就會生圖。真人、同學、證件、廁所照會先攔截。天氣、植物、車子等一般主題會畫。
  • 功課引導： 直接要標準答案時，會改成提示與反問，而不是把完整解答倒出來。

Pipeline：進站檢查，出站再還原

1. 兒童輸入文字送出後先進閘道。文字，加上可選的照片。有人臉只記數量，原圖不送進模型。
2. 進站鏈PII 代號化 → 內容安全 → 蘇格拉底 → 家長稽核。
3. Gemini通過才呼叫文字模型。通過才呼叫。生圖走 flash-image（禁止真人）；允許的照片會先遮碼再當圖片送出。
4. 出站鏈再審一次 → 補引導問句 → 稽核 → 還原真名給兒童。

Vault 今日是行程內記憶體，介面可換成 Redis。內容安全是台灣兒少不宜片語表，人像改圖要「有臉 + 改圖意圖」才額外攔截；Presidio 只負責個資，不管分級。
