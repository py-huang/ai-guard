兒童視角 · 這頁給使用者

這頁模擬小朋友看到的畫面。請打一句含姓名、學校、電話或地址的話；模型不會看到真名。

這一輪保護了什麼

說明

對話進行時，這裡只摘要「擋下幾筆個資」。完整對照在「實驗證明」分頁，避免把真名一直攤在兒童畫面旁。

這不是「AI 比較會聊天」，而是「兒童的真名進不了模型」

生成式模型一旦看到姓名、電話、身分證或住址，就可能寫進訓練對話、日誌，或在後續回合講出來。K-12 場景裡，小孩很常主動報上這些資料。

AI Guard 在呼叫 Gemini 之前 把台灣格式的個資換成穩定代號。模型若要提到這個人，它只能說 <PERSON_1>；出站時再還原給小朋友聽。對兒童的幫助是可檢查的：打開「實驗證明」，對照「原文」與「實際送到 LLM」。

  • 降低外洩面： Google 端看不到真名、真電話、真身分證。
  • 仍能對話： 代號在同一 session 固定，所以「王小明」連續兩句仍是同一個人。
  • 不過度承諾： 內容審核、家長稽核、完整蘇格拉底教學引擎尚未實作，見「真正做到的功能」。

Pipeline：進站代號化，出站再還原

1. 兒童輸入含台灣姓名、學校、電話、身分證、地址。
2. TaiwanPIIPresidio 自訂 recognizer + 身分證 checksum。寫入 Session Vault。
3. Gemini只收到 <PERSON_1> 這類記號。System prompt 禁止猜真名。
4. 還原用同一份 vault 把記號換回原文，給兒童看。

預設鏈：inbound 為 PII → ContentSafety（stub）→ Socratic（stub）；outbound 為 ContentSafety → ParentAudit（stub）→ PII 還原。Stub 會留下步驟名稱，但不會改寫內容。

Vault 今日是行程內記憶體（InMemorySessionVault），介面可換成 Redis，避免個資落地。
